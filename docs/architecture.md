# 开发说明

## 技术选型

固定 Godot 4.7.2，而不是跟随 latest。GDScript 避免 Android C# 工具链；Compatibility 渲染器降低设备兼容门槛。货架、包装和卡牌是真实 3D 网格，编辑器使用 Control + CanvasItem；卡牌画布经 SubViewport 输出为正反面贴图。Shader 随视角和时间生成金光、镭射、彩色光泽。

不引入服务器、账号、远程素材和支付。JSON 足以覆盖当前单机规模，后续收藏数量到数万张时可迁移 SQLite，并保持图片内容寻址不变。

## 模块

| 文件 | 职责 |
| --- | --- |
| scripts/store.gd | 原子抽卡、账本、存档、原图导入、备份和保险箱访问控制 |
| scripts/main.gd | 导航、系列、卡牌、收藏、拆包流程 |
| scripts/editor.gd | 图层属性、模板、历史、通用卡背 |
| scripts/card_canvas.gd | 统一 2D 卡面绘制、图层选取和手柄 |
| scripts/objects.gd | 正反卡面、原模型包装、圆角卡牌 |
| scripts/stage.gd | 3D 货架、相机、碰撞选择和旋转 |
| shaders/foil.gdshader | 特效材质 |

## 存档事务

一笔购买在内存中完成抽取、减库存、扣币、收藏快照和记账，先写 `.tmp` 并 flush，再备份上一有效存档并 rename 替换主存档；任一步失败回滚内存，只有持久化成功后才播放拆包动画。动画中关闭进程不会丢失卡牌。存档损坏时优先恢复 `.bak`，两代都损坏时停止写入并允许用户恢复 ZIP。JSON 不作为防作弊格式。

稀有度由实际剩余张数决定；评级只控制标记与默认视觉，不另设隐藏抽取权重。修改剩余张数相当于补充/调整印量。

原图以 SHA-256 命名并复制，不覆盖已有文件。备份携带 JSON 和所有导入原图；恢复前检验版本与基本数据结构并阻止目录穿越。仅支持本应用生成的备份。

## 本机验证与真机验收

运行 `tests/run.tscn -- --test`。测试使用独立目录，不修改真实数据。

真机应检查：

1. Android 竖屏、状态栏/挖孔/系统导航区域，360 度拖动、拆包动画与发热。
2. 从系统相册、文件管理器导入 PNG/JPEG/WebP/SVG，关闭重开后仍可显示。
3. 含透明边框、超大图片、多图层、多行中文的编辑保存和旋转。
4. 导出 ZIP 到系统文件目录，另一台设备恢复，确认原图和收藏一致。
5. 动画中强制关闭、连续快速点击购买、最后一包库存、余额不足。

后续可改善：图层多选/吸附、包装撕裂遮罩与音效、收藏去重计数和分页、SQLite 迁移，以及更高精度牌面预览。

## 0.2.0 修复

- 包装使用原 glTF 网格，归一化坐标后细分原三角面并增加 0.035 单位的双面弧度；银色封口保留原 UV 纹理。包身材质降低高光，不通过曝光抬亮封面。
- 长按按钮累计 1.8 秒，实时驱动银边撕开；释放暂停，离开窗口停止按住；达到终点才执行原子购买。中途返回不收费。
- 保险箱解锁状态仅在内存，后台/失焦锁定，启动不恢复解锁。筛选同时覆盖设计、货架、库存抽取、收藏、模板与交易中的系列名称。编辑草稿隐藏保留，重新验证密码才恢复。
- ZIP 在本地完成封装后顺序写入 Android 文档 URI，导入 URI 同样先缓存为可 seek 文件。未在 Android 真机验证提供方差异。
